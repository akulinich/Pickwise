# Pickwise Matchup Exporter

This unpacked Manifest V3 Chrome extension exports the matchup table currently
open on HSGuru or HSReplay. It runs only after the user clicks **Export CSV**.
The result is downloaded locally and no data is sent to Pickwise or any server.

## Install

1. Unzip the Pickwise extension archive.
2. Open `chrome://extensions` in desktop Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and choose this folder.
5. Pin **Pickwise Matchup Exporter** from the Extensions menu.

## Use

1. Click the extension and choose **Open HSGuru** or **Open HSReplay**.
2. The extension opens the matchup page with **Legend** and **Last 3 days** selected.
3. After the table loads, click the extension and then **Export current tab to CSV**.
4. In Pickwise, click **Import CSV** and choose the downloaded file.
